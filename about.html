About the branch

A campus home for people who want to build, teach, and ship.

IEEE NUCES PWR supports technical learning, collaboration, leadership, and public documentation for the FAST NUCES Peshawar student community.

Mission

Turn student curiosity into visible technical work.

The branch creates space for students to learn by organizing workshops, joining competitions, preparing sessions, and documenting outcomes that future teams can build on.

Its work is practical: speaker coordination, event execution, media coverage, web publishing, member support, and technical mentoring.

How work moves

A practical operating model for student contributors.

Each team owns a visible part of the branch. That keeps responsibilities clear and makes it easier for new members to find useful work quickly.

01

Plan the session

Pick a clear learning outcome, speaker, venue, and promotion window.

02

Run the event

Coordinate registrations, media, certificates, logistics, and attendee support.

03

Publish the record

Add photos, outcomes, and reports so future teams can reuse the work.
