🚀 How to View Your Website

Option 1: Direct Open (Easiest)

Simply double-click index.html to open it in your default browser.

Option 2: Using VS Code Live Server
  1. Install "Live Server" extension in VS Code
  2. Right-click on index.html
  3. Select "Open with Live Server"
Option 3: Python Simple Server

In the terminal, run:

python -m http.server 8000

Then open: http://localhost:8000

🎨 Customization Tips

To Change Colors:

Look for ieee-blue and ieee-blue-dark in the files and replace with your preferred colors.

To Update Images:

Replace placeholder URLs (via.placeholder.com) with your actual image URLs. You can use:

  • Direct image URLs from your server
  • Image hosting services (Imgur, Cloudinary, etc.)
  • Relative paths to local images
To Add/Edit Events:

Open script.js and modify the eventsData array.

To Add Team Members:

Copy and paste the team member HTML blocks in index.html and update the information.
