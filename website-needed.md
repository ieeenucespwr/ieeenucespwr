# IEEE Student Branch Website - Visual Description

This is a modern, professional single-page website for the IEEE NUCES PWR Student Branch with the following visual characteristics:

## Overall Design Style
- **Modern & Clean**: Uses Tailwind CSS with a contemporary, minimalist design aesthetic.
- **Font**: Poppins font family throughout (Google Fonts).
- **Animations**: Smooth scroll-triggered animations using AOS (Animate On Scroll).
- **Particle Effects**: Animated particle.js background in the hero section.
- **Dark Mode Support**: Toggle between light/dark themes.
- **Mobile Responsive**: Fully responsive design with dedicated mobile menu.

## Navigation Bar (Top, Fixed)
- Transparent white background with blur effect (glassmorphism).
- IEEE logo on the left.
- Horizontal navigation links in center: About Us, Events, Member Spotlight, Testimonials, Courses, Join Us.
- Dark mode toggle button and mobile hamburger menu on right.
- Progress indicator bar showing scroll position.

## Hero Section
- Full-width animated background with particle effects.
- Large heading: "IEEE NUCES PWR Student Branch".
- Tagline about building technology for humanity.
- Two call-to-action buttons: "Learn More" and "Upcoming Events".
- Gradient overlays creating depth.

## About Section (White background)
Contains four distinct subsections:

### 1. Faculty Head
- **Left**: Large circular photo with blue border.
- **Right**: Gradient blue-to-indigo card with Dr. Suleman Mir's details.
    - Includes title, credentials, description, LinkedIn and email icons.

### 2. Executive Body 2025-26
- Three elegant flip cards in a row: Vice Chairperson (Usman Sohail), Chairperson (Abdullah Asim), General Secretary (Dilawer Khan).
- Cards feature full background images with gradient overlays.
- On hover, cards reveal detailed information and social links.

### 3. Team Categories
- Eight team sections, each with:
    - Icon representing the team function.
    - Team name (Graphics, Web Development, Marketing, Operations, Media, Content Creation, Event Coordination, Decor).
    - Description paragraph.
    - Grid of member cards with circular photos and names.
    - Team leads have larger photos.
    - Color-coded icons (palette, code, bullhorn, cogs, camera, pen, calendar, paint-brush).

### 4. General Body Members
- Grid of smaller circular profile pictures with names.
- Simple, uniform layout.

## Events Section (Gray background with circuit pattern)
- Section heading.
- 3-column grid of event cards.
- Cards populated dynamically via JavaScript.
- Clean card design with shadows.

## Member Spotlight Section (White background)
- 2-column grid layout.
- Dynamically populated content cards.
- Features notable members and their achievements.

## Testimonials Section (Gray background)
- 3-column grid.
- Quote-style cards with member feedback.
- JavaScript-driven content.

## Professional Courses Section (White background)
- Prominent heading with descriptive subheading.
- Four feature badges: Expert Instructors, Hands-on Projects, Certificate of Completion, Networking Opportunities.
- Filter buttons: All Courses, Programming, Hardware, Soft Skills, Certification.
- 3-column grid of course cards featuring:
    - Course images (web-dev, arduino, machine learning, leadership, mobile-dev, robotics).
    - Badge labels (Beginner/Intermediate/Advanced).
    - Ribbon tags (Popular/New).
    - Enrollment numbers and star ratings.
    - Duration, hours, and difficulty level icons.
    - Pricing with strikethrough discounts.
    - "Learn More" buttons.
- Call-to-action section at bottom with gradient background.

## Footer (Dark background)
- IEEE white logo.
- Three-column layout:
    - **Quick Links**: About, Events, Courses, etc.
    - **Resources**: IEEE Global, Membership, Xplore.
    - **Contact information**: Phone, email.
- Social media icons (Facebook, Twitter, Instagram, LinkedIn, YouTube).
- Copyright notice at bottom.

## Mobile Features
- Slide-in side menu from right.
- Dark mode toggle in mobile menu.
- Collapsible navigation.
- Overlay backdrop when menu is open.

## Color Scheme
- **Primary**: Blues and indigos.
- **Accent**: Purple for links and hover states.
- **Neutral**: Grays for text and backgrounds.
- White and light gray alternating sections for visual separation.
- Gradient overlays (blue-to-indigo, blue-50 to indigo-100).

## Interactive Elements
- Hover effects on all buttons and cards.
- Smooth scroll navigation.
- Animated particles in hero.
- Card flip/reveal animations.
- Course filtering system.
- Dark mode toggle with icon switching.

The website presents a professional, tech-forward image suitable for a student engineering organization, with excellent information hierarchy and visual appeal.
