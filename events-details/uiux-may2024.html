UI/UX Design Workshop

📅 Date: May 16, 2024
⏰ Duration: 2 Hours (CPD)
👥 Attendees: 55+ Students
🎓 Batches: 2021-2024

Event Overview

The UI/UX Design Workshop provided comprehensive hands-on training in user interface and user experience design principles. This interactive session introduced students to the world of design thinking, user-centered design, and practical tools used in the industry.

Participants explored both theoretical foundations and practical applications, learning how to create intuitive, aesthetically pleasing, and functional digital interfaces.

Key Topics Covered

  • Design Thinking: Understanding user needs through empathy and research
  • User Research Methods: Interviews, surveys, and usability testing techniques
  • Wireframing: Creating low-fidelity layouts and information architecture
  • Prototyping: Building interactive mockups using tools like Figma and Adobe XD
  • Visual Design: Color theory, typography, and layout principles
  • Usability Testing: Evaluating designs with real users and iterating
  • Design Systems: Creating consistent, reusable component libraries

Session Highlights

The workshop included:

  1. Hands-on exercises designing mobile app interfaces
  2. Live demonstrations of Figma and prototyping tools
  3. Group activities practicing user journey mapping
  4. Case studies of successful UI/UX design projects
  5. Feedback sessions on participant design work

Students gained practical skills in using industry-standard design tools and understanding the complete design process from research to implementation.
