🔑 GitHub Token Authentication

Sign in to the CMS using a GitHub Personal Access Token (PAT) with repository access. This allows editing content on GitHub Pages without a backend proxy.

How to create a token:
Fine-Grained Token Recommended
  1. Open GitHub Fine-Grained Token Settings.
  2. Repository access: Choose "Only select repositories" → ieeenucespwr/ieeenucespwr (or your fork).
  3. Permissions: Grant:
    • Contents: Read and write
    • Pull requests: Read and write
  4. Generate the token, copy it, and paste it above.
Classic Token (Alternative)
  1. Open GitHub Token Settings (classic).
  2. Select the repo scope (Full control of all private and public repositories).
  3. Generate the token, copy it, and paste it above.
