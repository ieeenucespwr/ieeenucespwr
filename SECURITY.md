# Security Policy

This is a static public website, but security issues can still happen through links, forms, dependencies, and exposed private information.

## Supported Version

The `main` branch is the supported version.

## Reporting a Vulnerability

Email `info@ieeenucespwr.org` with:

- A short description of the issue
- The affected page or file
- Steps to reproduce, if applicable
- Suggested fix, if you have one

Do not open a public issue for private data exposure or credential leaks.

## Security Expectations

- Do not commit secrets, tokens, private student data, or unpublished contact lists.
- Review external links before merging.
- Keep GitHub Pages deployment permissions limited to what the workflow needs.
